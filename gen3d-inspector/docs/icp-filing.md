# ICP 备案实操攻略（Gen3D Inspector 适用）

> 对应问题：「没有备案，备案麻烦吗？马上可以备案。」
> 结论先给：**不麻烦，但有三条硬门槛，缺一条都提交不了。全程线上、免费，时间成本约 2–4 周。**

---

## 1. 一句话结论

备案本身是**填表 + 上传证件 + 等审核**，没有技术难度，也不花钱。
真正会卡住你的是「资质条件」而不是「操作难度」：

| 硬门槛 | 说明 | 你现在的状态 |
| --- | --- | --- |
| ① 一个**已实名认证**的域名 | 后缀在国家批复列表内，且必须由**境内注册商**管理 | ❓ 需要先买 / 转入 |
| ② 一份符合条件的**腾讯云大陆云资源** | COS **不算**，见 §2 | ❌ 需要先买 |
| ③ 账号完成**实名认证** | 个人身份证即可 | ❓ 需确认 |

三条齐了，剩下的就是走流程。**备案不收费**（腾讯云不收，管局也不收）。

---

## 2. 门槛 ②：备案必须挂在一个「大陆云资源」上

腾讯云的规定是：账号下要存在满足条件的大陆云资源，才能发起备案。任一即可：

| 方式 | 要求 | 大致成本 |
| --- | --- | --- |
| **轻量应用服务器 Lighthouse**（推荐） | 大陆节点、包年包月 ≥ 3 个月、备案期间剩余有效期 ≥ 1 个月 | 新用户促销约 ¥38–88/年；常规约 ¥100+/年 |
| **云服务器 CVM** | 大陆节点、有公网 IP、包年包月 ≥ 3 个月、剩余 ≥ 1 个月 | 比轻量贵 |
| **Serverless（云函数 SCF）资源包** | 每账号限购 1 个，可备案 2 个网站；需同时买 5000 万次调用包 + 40 万 GBs 用量包 | 需到资源包购买页确认当期价格 |
| **云托管资源包** | 剩余有效期 ≥ 3 个月 | 2021-08-05 起**不再支持新增域名备案**，存量可用 |
| **备案授权码** | 由有合格服务器的账号生成，一码只能备案一个网站 | 个人账号不支持生成，仅企业账号可生成 |

### 2.1 最容易踩的坑

**对象存储 COS 不在这个列表里。** 所以「先买 COS → 去备案」这个顺序**不成立**。必须先把上面某个资源买了，才能提交备案。

### 2.2 便宜且省事的组合（推荐）

1. 买一台**最低配轻量应用服务器**（大陆节点，包年包月，至少 3 个月，建议直接买 1 年）；
2. 用它作为备案资质，走完备案；
3. 网站内容**仍然放 COS**（静态包 5 MB 不到，用轻量也行，但 COS + CDN 更省心）；
4. **建议保留这台轻量**。备案号绑定的是主体和域名，但接入商信息是腾讯云；如果把唯一的云资源退掉，后续做接入核验时可能被要求补充资源，¥88/年 买个安心。

---

## 3. 门槛 ①：域名要求（三条都要满足）

1. 后缀在**国家批复的可备案域名后缀**列表内（`.com` / `.cn` / `.net` / `.top` / `.xyz` 等常见后缀都在）；
2. 由**境内有资质的注册服务机构**管理。
   ⚠️ **境外注册商注册的域名不能直接备案**，必须先转入境内服务商（如腾讯云）。如果你的域名在 Cloudflare / Namecheap / GoDaddy，要预留转入时间（转入一般 5–7 天）。
3. 域名**已完成实名认证**，且实名主体与备案主体**完全一致**，域名在有效期内。

> 实操建议：直接在腾讯云注册一个新域名，实名认证通常几分钟内通过，省掉转入环节。
> 域名费用约 ¥30–80/年（`.top` / `.xyz` 等便宜后缀更低）。

---

## 4. 完整流程与时间

按腾讯云官方文档的流程：

| 步骤 | 内容 | 耗时 |
| --- | --- | --- |
| 1 | 微信扫小程序码进入备案小程序（或用 PC 端备案控制台） | 即时 |
| 2 | 登录腾讯云账号，**验证备案类型**（选省份 / 个人或企业 / 域名 / 云资源） | 数分钟 |
| 3 | 填**主体信息**（个人：姓名、身份证、手机号、通信地址） | 数分钟 |
| 4 | 填**网站信息**（网站名称、服务内容、域名） | 数分钟 |
| 5 | **视频核验** + 上传证件照片 | 数分钟 |
| 6 | 提交腾讯云**初审** | **1–2 个工作日** |
| 7 | **工信部短信核验**：工信部系统下发验证码，须在 **24 小时内**到工信部备案管理系统完成核验 | 即时（别漏，漏了要重来） |
| 8 | 提交**省通信管理局**审核 | 各省不同，**法定上限 20 个工作日** |

### 4.1 各省管局参考时长（腾讯云官方表格节选）

| 省份 | 预估 | 省份 | 预估 |
| --- | --- | --- | --- |
| 上海市 | 5–10 工作日 | 广东省 | 8–15 工作日 |
| 北京市 | 15–17 工作日 | 浙江省 | 7–10 工作日 |
| 四川省 | 11–12 工作日 | 江苏省 | 9–30 工作日 |
| 山东省 | 10–13 工作日 | 湖北省 | 8–12 工作日 |
| 福建省 | 6–9 工作日 | 陕西省 | 7–10 工作日 |

**合计预期：2 周左右（快）到 4 周（慢）。** 工作日不含周末和法定节假日。

### 4.2 审核期间要注意

- 首次备案，**备案成功前域名不能解析到大陆节点访问**（解析开了会被要求关闭）。
- 审核期间管局可能打**核验电话**，保持手机畅通。
- 管局审核结果通过短信 / 邮件通知，**无法催审**。

## 5. 个人备案的额外约束（重要）

个人主体备案**不需要营业执照**，但内容上有明显限制：

- 网站服务内容需选**个人类目**（如「个人技术博客 / 作品展示 / 其他」）；
- **不能出现商业内容**：联系方式、二维码、价目表、销售信息、招商合作等，被发现会驳回；
- 网站名称不能涉及企业名号、行业词、地域词（如「XX 科技」「XX 工作室」类名称风险较高）；
- 部分省份对个人备案审核更严，会要求网站名称与内容强相关。

**对 Gen3D Inspector 的影响：**
这是一个**技术作品集 / 在线工具站**，属于个人非经营性内容，个人备案是合适的。
需要注意的是页面底部要按要求标注备案号（备案通过后我会加上），并且不要在站内放「接单 / 报价 / 商务合作」这类模块。

> 如果你未来打算用它接商业项目，建议从一开始就走**企业主体备案**——个人备案不能变更为企业备案，只能注销重备。

---

## 6. 备案通过之后

1. 在页面底部加上备案号，并链接到 `https://beian.miit.gov.cn/`（管局要求，不加会驳回）；
2. 把域名解析到**大陆** COS 桶或大陆 CDN 加速域名（此时不需要再备案，域名已备案即可）；
3. 大陆 CDN 加速域名同样要求域名已备案；
4. HTTPS：申请腾讯云**免费 DV 证书**（见 §7）。

---

## 7. 关于 HTTPS 证书（你问的「没有 HTTP 证书」）

**不需要买证书。** 腾讯云提供免费 DV 证书：

| 项 | 免费 DV 证书 |
| --- | --- |
| 有效期 | **90 天**，到期需重新申请（不支持续费） |
| 域名类型 | 仅**单个**域名，**不支持通配符** |
| 数量 | 每个腾讯云账号最多 **50 张** |
| 签发 | TrustAsia |
| 验证方式 | 自动 DNS 验证（域名在腾讯云解析时最省事）/ 手动 DNS / 文件验证 |
| 审核 | 通常 1 个工作日内签发 |

**实操建议：**
- 只给**实际用的那个主机名**（如 `gen3d.example.com`）申请一张，不用管通配符；
- 如果走腾讯云 CDN，可以把域名交给支持**自动续签**的加速平台托管，省掉每 90 天手动换证书；
- 免费证书官方定位是「前期测试使用」，正式项目长期跑建议后续换成付费证书，但个人作品集用免费证书完全够。

---

## 8. 落地顺序建议（最省时间的排法）

```
今天    ① 注册域名（腾讯云） → 实名认证
今天    ② 买最低配轻量服务器（大陆，包年包月，≥3 个月）
今天    ③ 提交备案申请（小程序，约 30 分钟填完）
  ↓     备案审核中（1–20 个工作日）——这段时间网站可以照常放香港节点对外用
未来    ④ 拿到备案号 → 页面加备案号 → 解析切到大陆 COS/CDN → 申请免费证书开 HTTPS
```

**关键点：备案和建站可以并行。** 审核期间用香港节点先对外访问，备案一下号就切到大陆节点，代码一行都不用改（同一份 `dist-static/`，只换 bucket 地域和解析）。

## 9. 照着点就行：控制台直达链接

按顺序走，前两步今天就能完成。

| 步骤 | 做什么 | 直达链接 |
| --- | --- | --- |
| 0 | 确认腾讯云账号已完成**实名认证** | https://console.cloud.tencent.com/developer |
| 1 | **注册域名**（建议选 `.top` / `.xyz`，最便宜；实名认证几分钟通过） | https://console.cloud.tencent.com/domain |
| 2 | **买最低配轻量应用服务器**（选**中国大陆**地域，包年包月 ≥3 个月） | https://buy.cloud.tencent.com/lighthouse |
| 3 | **提交备案**（首次备案，小程序扫码或网页版） | https://console.cloud.tencent.com/beian |
| 4 | 备案通过后：创建**大陆 COS 桶**并绑域名 | https://console.cloud.tencent.com/cos |
| 5 | 申请**免费 DV 证书**并绑定 | https://console.cloud.tencent.com/ssl |
| 6 | （可选）开 **CDN 加速**，域名需已备案 | https://console.cloud.tencent.com/cdn |
| 7 | 配 **DNS 解析**（CNAME 指向 COS/CDN 给的地址） | https://console.dnspod.cn/dns |
| 8 | 查备案号是否已下发 | https://beian.miit.gov.cn/ |

> 第 1、2 步完成当天就能提交第 3 步。备案审核期间，我可以先用**香港节点**把站点架起来对外访问，
> 备案一下号再切到大陆节点 —— 用的是同一份 `dist-static/` 产物，代码一行都不用改。
