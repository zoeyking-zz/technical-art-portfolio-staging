# Blender 实时动捕与虚拟角色工具

## 项目概述

个人本科项目。目标是在 Blender 中接收实时动捕数据，并把角色驱动、镜头控制、面部参数和舞台辅助功能集中到统一工具面板中，减少动画测试时反复切换窗口和手工配置的步骤。

## 个人工作

- 搭建可穿戴人体动捕与单目面捕到 Blender 角色的实时驱动流程；
- 开发 Blender 动画辅助面板，整合 Camera Tracking、Facial Slider、粒子实例化和常用动画操作；
- 处理动捕骨骼与角色 Skeleton 的映射及兼容问题；
- 设计、测试并录制完整演示。

历史项目记录显示：端到端反馈延迟约为 80 ms，部分高频操作流程效率提升 90% 以上。原工程与源码现已无法找回，因此这些数字无法在当前仓库中重新测量。
